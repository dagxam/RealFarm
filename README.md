# RealFarm 🌾

Сельскохозяйственный **Paper-плагин** для Minecraft.

## Первый рабочий фундамент — замкнутая пашня

Пашня создаётся как квадрат из **любых блоков по периметру**.

Внутри квадрата:

- поверхность — `FARMLAND`;
- допускается один котёл;
- рядом с котлом можно поставить один стандартный `COMPOSTER`;
- культуры высаживаются на пашне.

Если квадрат не замкнут или внутри нет котла, культуры не растут и игроки рядом получают сообщение:

`Пашня не готова: внутри замкнутого квадрата нужен котёл.`

Если котёл есть, но он заполнен не полностью:

`Нет воды: полностью заполните котёл водой.`

### Вода

Полностью заполненный водой стандартный котёл поддерживает пашню случайно **2–3 игровых дня**, после чего вода полностью расходуется и котёл становится пустым.

### Компостер / удобрение

Используется стандартный `COMPOSTER` из Minecraft.

- принимает для RealFarm только костную муку;
- уровень заполнения показывается стандартной моделью компостера;
- после полного заполнения ускоряет рост;
- эффект действует случайно **3–5 игровых дней**;
- после окончания действия компостер автоматически становится пустым.

### Рост культур

RealFarm отменяет обычный случайный рост культур внутри зарегистрированной пашни и выращивает их по собственному таймеру.

Обычный рост до зрелости занимает случайно **2–5 игровых дней**. Полный компостер ускоряет прохождение стадий роста.

### Проверка пашни

Посмотрите на блок внутри готовящейся пашни и используйте:

`/realfarm status`

Команда показывает:

- найден ли замкнутый квадрат;
- размер пашни;
- есть ли котёл;
- есть ли полная вода;
- состояние компостера;
- активно ли ускорение роста.

## Сборка

В репозитории добавлен GitHub Actions. После отправки изменений в `main` плагин автоматически собирается Maven и JAR сохраняется как артефакт `RealFarm`.

## План развития

### Этап 1 — Основа
- система регистрации культур;
- стадии роста;
- посадка семян;
- сбор урожая;
- кукуруза, томат, огурец, капуста.

### Этап 2 — Земля и полив
- плодородие;
- полив;
- удобрения;
- ускорение роста.

### Этап 3 — Сады
- саженцы;
- яблоня;
- груша;
- вишня;
- плоды непосредственно на деревьях;
- повторный урожай без уничтожения дерева.

### Этап 4 — Переработка
- мельница;
- мука;
- сок;
- варенье;
- сыр;
- масло;
- комбикорм.

### Этап 5 — Интеграция с сезонами
- сезоны влияют на скорость роста;
- зимой некоторые культуры не растут;
- весной повышенный рост;
- осенью меняется урожайность отдельных растений.

## Принцип проекта

RealFarm создаётся как обычный Paper-плагин. Пока используются стандартные блоки и предметы Minecraft, без обязательного ресурспака и без клиентского мода. Позже можно добавить кастомные визуальные модели и интеграцию с отдельным плагином сезонов.

## Команды

`/realfarm info` — информация о плагине.

`/realfarm status` — проверка текущей пашни.

`/realfarm reload` — перезагрузка конфигурации.
