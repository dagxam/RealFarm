# RealFarm 🌾

Сельскохозяйственный **Paper-плагин** для Minecraft.

## Цель проекта

RealFarm будет добавлять полноценную систему сельского хозяйства без обязательных модов и с постепенным развитием от стандартных Minecraft-механик к более глубокой фермерской системе.

## План развития

### Этап 1 — Основа
- система регистрации культур;
- стадии роста;
- посадка семян;
- сбор урожая;
- кукуруза, томат, огурец, капуста.

### Этап 2 — Земля и полив
- плодородие;
- полив;
- удобрения;
- ускорение роста.

### Этап 3 — Сады
- саженцы;
- яблоня;
- груша;
- вишня;
- плоды непосредственно на деревьях;
- повторный урожай без уничтожения дерева.

### Этап 4 — Переработка
- мельница;
- мука;
- сок;
- варенье;
- сыр;
- масло;
- комбикорм.

### Этап 5 — Интеграция с сезонами
- сезоны влияют на скорость роста;
- зимой некоторые культуры не растут;
- весной повышенный рост;
- осенью меняется урожайность отдельных растений.

## Принцип проекта

Сейчас RealFarm создаётся как обычный Paper-плагин. На первом этапе используются стандартные возможности Minecraft, без обязательного ресурспака и без клиентского мода. Архитектура закладывается так, чтобы позже можно было добавить визуальные модели, кастомные предметы и интеграцию с отдельным плагином сезонов.

## Команда

`/realfarm info` — информация о плагине.

`/realfarm reload` — перезагрузка конфигурации.
