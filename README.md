# 🌾 RealFarm

> **Сельскохозяйственный Paper-плагин для Minecraft** с собственными участками, поливом, удобрением, контролируемым ростом культур и деревьев, сезонной влажностью и парниками.

RealFarm делает фермерство более живым, но пока использует **только стандартные блоки и предметы Minecraft** — без обязательного ресурспака и без клиентского мода.

# 🌱 Как создать участок

Участок RealFarm — это **единая связная группа блоков `FARMLAND`**.

Форма **не имеет значения**. Не нужен квадрат, рамка или замкнутый периметр.

Главное правило:

> Все блоки пашни одного участка должны соединяться между собой без разрывов.

### Примеры допустимой формы

```text
██████
██
████
   ██
```

```text
███████
█
███████
```

```text
  ███
██████
  ███
```

Пустой промежуток разрывает участок на разные части.

### Размер участка

По текущей конфигурации:

- минимальный размер — **3 блока пашни**;
- максимальный размер — **15 блоков пашни**.

Эти значения можно изменить в `config.yml`.

# 🪣 Котёл фермы

Котёл фермы — специальный предмет RealFarm, который выглядит как обычный котёл Minecraft, но помечен внутренними данными плагина.

## 🔨 Крафт

Третий ряд верстака должен быть пустым:

```text
┌────────┬─────────────┬────────┐
│ ЖЕЛЕЗО │ КОСТНАЯ    │ ЖЕЛЕЗО │
│        │ МУКА        │        │
├────────┼─────────────┼────────┤
│ ЖЕЛЕЗО │ ЖЕЛЕЗО      │ ЖЕЛЕЗО │
├────────┼─────────────┼────────┤
│        │             │        │
└────────┴─────────────┴────────┘
```

**Результат:** 🪣 `Котёл фермы`

### Расположение

Котёл должен стоять **вплотную к любому блоку пашни участка**:

```text
🪣 🌱 🌱 🌱
   🌱 🌱 🌱
   🌱 🌱 🌱
```

Можно поставить с любой из четырёх боковых сторон.

Между котлом и пашней **не должно быть пустого блока**:

```text
🪣 ⬜ 🌱   ❌ не работает
🪣 🌱      ✅ работает
```

### Вода

Для увлажнения достаточно **любого уровня воды** в котле:

- `1/3` — работает;
- `2/3` — работает;
- `3/3` — работает.

Полностью заполнять котёл не требуется.

После появления воды плагин запускает случайный таймер расхода. Вода расходуется через **2–3 игровых дня Minecraft** и котёл становится пустым.

# ♻️ Компостер фермы

Компостер фермы также выглядит как стандартный компостер Minecraft, но является специальным блоком RealFarm.

## 🔨 Крафт

Третий ряд верстака должен быть пустым:

```text
┌────────┬─────────────┬────────┐
│ ДОСКИ  │ КОСТНАЯ    │ ДОСКИ  │
│        │ МУКА        │        │
├────────┼─────────────┼────────┤
│ ДОСКИ  │ ДОСКИ       │ ДОСКИ  │
├────────┼─────────────┼────────┤
│        │             │        │
└────────┴─────────────┴────────┘
```

**Результат:** ♻️ `Компостер фермы`

В текущей версии для крафта используются **дубовые доски**.

### Как заполнить

Компостер фермы принимает **только костную муку**.

Нажимайте ПКМ по компостеру, держа костную муку в руке:

```text
🦴 костная мука → ♻️ компостер → ускорение роста
```

Уровень заполнения отображается **стандартной моделью компостера Minecraft**.

Для работы удобрения достаточно любого уровня выше нуля.

### Действие удобрения

После первого внесения костной муки удобрение действует случайно **3–5 игровых дней**. По окончании этого времени компостер автоматически очищается.

Компостер:

- необходим для полной активности участка;
- ускоряет рост зарегистрированных культур;
- ускоряет рост деревьев RealFarm;
- **не отвечает за влажность пашни**.

---

# ⚙️ Когда участок считается активным

Для полноценной активности участка одновременно нужны:

- 🪣 Котёл фермы рядом с пашней;
- ♻️ Компостер фермы рядом с пашней;
- 💧 хотя бы немного воды в котле;
- 🦴 хотя бы немного костной муки в компостере.

Если отсутствует хотя бы один элемент, участок получает статус:

```text
НЕ АКТИВНО
```

Если всё присутствует:

```text
АКТИВНО
```

При неактивном участке RealFarm сообщает причину:

- нет котла фермы;
- нет компостера фермы;
- нет воды в котле;
- нет костной муки в компостере.

> Важно: **активность участка и влажность пашни — разные механики**. Например, компостер не удерживает влагу, а дождь или парник могут удерживать пашню влажной независимо от состояния компостера.

# 💧 Влажность и расход воды

Открытая пашня RealFarm управляется плагином.

### Если есть вода

Весной и летом вода в Котле фермы удерживает участок полностью влажным.

### Если воды нет

При обычной сухой погоде пашня начинает высыхать.

### Дождь

Во время дождя открытая пашня остаётся влажной даже без воды в котле.

### Компостер

Наличие или отсутствие костной муки **не влияет на влажность**.

---

# 🌦️ Погода и сезоны

RealFarm поддерживает интеграцию с **RealisticSeasons**.

Если `RealisticSeasons` установлен и его API доступен, RealFarm автоматически получает текущий сезон мира:

- 🌸 `SPRING` — весна;
- ☀️ `SUMMER` — лето;
- 🍂 `FALL` — осень;
- ❄️ `WINTER` — зима.

## Сезонная логика открытой пашни

| Условие | Состояние пашни |
|---|---|
| 🌧️ Идёт дождь | Всегда влажная |
| 🌸 Весна + есть вода | Влажная |
| ☀️ Лето + есть вода | Влажная |
| 🍂 Осень | Высыхает даже при наличии воды |
| ❄️ Зима | Принудительно полностью сухая |
| ☀️ Нет дождя + нет воды | Высыхает |

После зимы цикл сезонов снова продолжается.

### Если RealisticSeasons не установлен

RealFarm продолжает работать, но сезон определяется как неизвестный, поэтому используется обычная логика воды и дождя без сезонного принудительного высыхания.

# 🏡 Парники

Парник полностью защищает участок от сезонного высыхания.

## Требования к парнику

Участок должен быть:

- полностью закрыт **сверху стеклом**;
- полностью закрыт **по бокам стеклом**;
- без отверстий в стенах и крыше.

Поддерживаются:

- обычное стекло;
- цветное стекло;
- стеклянные панели;
- цветные стеклянные панели.

### Пример

```text
        СТЕКЛЯННАЯ КРЫША
     ┌───────────────────┐
     │                   │
СТЕКЛО│    🌱 🌱 🌱       │СТЕКЛО
СТЕКЛО│    🌱 🌱 🌱       │СТЕКЛО
     │                   │
     └───────────────────┘
```

### Эффект парника

Внутри правильно определённого парника пашня:

- 🌸 остаётся влажной весной;
- ☀️ остаётся влажной летом;
- 🍂 не высыхает осенью;
- ❄️ не высыхает зимой;
- 💧 не зависит от наличия воды для самой влажности.

Парник имеет **высший приоритет** над сезонными правилами.

При наведении на Котёл фермы или Компостер фермы показывается:

```text
Парник: ДА
```

или:

```text
Парник: НЕТ
```

> Текущий детектор проверяет крышу на высоте от 2 до 8 блоков над уровнем пашни.

# 🌾 Культуры

Рост зарегистрированных культур внутри участка RealFarm контролируется плагином.

### Текущие культуры

- 🌾 пшеница;
- 🥕 морковь;
- 🥔 картофель;
- 🟥 свёкла;
- 🌸 торчфлауэр;
- 🪷 кувшинковое растение.

### Рост

Обычное время полного роста:

> ⏳ **случайно 2–5 игровых дней**

Костная мука в Компостере фермы ускоряет рост согласно настройке `growth-multiplier`.

Прямое ускорение зарегистрированных культур костной мукой на участке RealFarm отключается — удобрение должно проходить через Компостер фермы.

### Проверка списка культур

```text
/realfarm crops
```

# 🌳 Деревья

## Саженец на пашне RealFarm

Стандартные саженцы, посаженные непосредственно на пашню активного участка RealFarm, переводятся под контроль плагина.

Поддерживаются:

- 🌳 дуб;
- 🌳 берёза;
- 🌲 ель;
- 🌴 джунгли;
- 🌳 акация;
- 🌳 тёмный дуб.

Рост занимает случайно **2–5 игровых дней**.

Для роста дерева необходима вода. Костная мука в Компостере фермы ускоряет рост.

## Саженец не на пашне RealFarm

RealFarm не вмешивается в ванильный рост:

```text
Саженец на обычной земле → обычный Minecraft-рост
Саженец на FARMLAND RealFarm → рост контролирует RealFarm
```

Таким образом обычные леса и фермы деревьев игроков не ломаются.

> Фруктовые деревья с повторным урожаем — отдельный следующий этап разработки.

# 👁️ Информация об участке

Посмотрите на Котёл фермы или Компостер фермы с небольшого расстояния.

В action bar отображается информация вида:

```text
Участок №1 | Пашня: 24 | Посажено: 18 |
Вода: 2/3 | Парник: ДА | АКТИВНО
```

Для компостера:

```text
Участок №1 | Пашня: 24 | Посажено: 18 |
Костная мука: 3/7 | Парник: НЕТ | АКТИВНО
```

Показывается:

- 🔢 номер участка;
- 🌱 количество блоков пашни;
- 🌾 количество посаженных культур и саженцев;
- 🪣 уровень воды;
- ♻️ уровень удобрения;
- 🏡 состояние парника;
- ⚙️ активен участок или нет.

# ⌨️ Команды и права

Все административные команды требуют право:

```text
realfarm.admin
```

По умолчанию оно доступно операторам сервера.

### `/realfarm info`

Показывает основную информацию о плагине и правила работы участков.

### `/realfarm status`

Посмотрите на блок пашни участка и выполните:

```text
/realfarm status
```

Команда показывает:

- номер участка;
- количество блоков пашни;
- наличие Котла фермы;
- наличие Компостера фермы;
- наличие воды.

### `/realfarm crops`

Показывает список включённых культур.

### `/realfarm reload`

Перечитывает `config.yml`.

# ⚙️ Настройка

Основной файл:

```text
plugins/RealFarm/config.yml
```

Пример текущей конфигурации:

```yml
farm:
  min-size: 3
  max-size: 15

water:
  consume-after-days-min: 2
  consume-after-days-max: 3

fertilizer:
  duration-days-min: 3
  duration-days-max: 5
  growth-multiplier: 2

crops:
  growth-days-min: 2
  growth-days-max: 5

trees:
  growth-days-min: 2
  growth-days-max: 5
```

### Служебные данные

Плагин автоматически сохраняет состояние в:

```text
plugins/RealFarm/farm-state.yml
plugins/RealFarm/tree-state.yml
```

Там хранятся специальные сервисные блоки, таймеры расхода ресурсов, номера участков и состояние контролируемых деревьев.

# 🧪 Установка

1. Скачайте собранный `RealFarm.jar`.
2. Поместите файл в папку:

```text
/plugins
```

3. При необходимости установите `RealisticSeasons` для сезонной интеграции.
4. Запустите сервер.
5. После первого запуска настройте `plugins/RealFarm/config.yml`.

RealFarm является **серверным Paper-плагином**. Клиентский мод не требуется.
